## 5. Memformat Teks

Menerapkan berbagai tag pemformatan teks untuk memberikan gaya atau penekanan tertentu, seperti:

* `<b>` dan `<strong>` untuk teks tebal
* `<i>` dan `<em>` untuk teks miring
* `<mark>` untuk memberikan tanda atau highlight
* `<sub>` untuk subscript
* `<sup>` untuk superscript

## 6. Menyisipkan Gambar

Menambahkan gambar ke dalam halaman web menggunakan tag `<img>` dengan atribut:

* `src` untuk menentukan lokasi file gambar
* `alt` untuk memberikan teks alternatif
* `title` untuk memberikan deskripsi gambar

Gambar yang digunakan disimpan di dalam folder `images/`.

## 7. Menambahkan Hyperlink

Membuat tautan atau hyperlink menggunakan tag `<a>` dengan atribut `href`.

Hyperlink digunakan untuk menghubungkan halaman web internal, seperti `halaman2.html`, maupun mengarah ke website eksternal.

## 8. Menambahkan List

Membuat daftar menggunakan dua jenis list HTML:

* **Unordered List (`<ul>`)** — digunakan untuk daftar tanpa nomor.
* **Ordered List (`<ol>`)** — digunakan untuk daftar yang berurutan atau menggunakan nomor.

## 9. Menambahkan Komentar

Menambahkan komentar atau catatan internal pada kode HTML menggunakan sintaks:

```html
<!-- Komentar -->
```

Komentar tidak akan ditampilkan pada halaman web dan hanya digunakan sebagai dokumentasi atau catatan dalam kode.
